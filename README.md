# 🌸 Thư Hoa & Lời Chúc 20/10 - Ngày Phụ Nữ Việt Nam

Trang web thiệp chúc mừng 20/10 với hiệu ứng 3D Three.js, phong thư tương tác bốc mở và những lời chúc ngọt ngào dành tặng một nửa thế giới!

## ✨ Tính năng nổi bật
- 🌹 **Bó hoa hồng 3D Three.js**: Tương tác xoay 360 độ, hiệu ứng rơi cánh hoa và ánh sáng lung linh.
- 💌 **Phong thư & Lời chúc**: Bấm mở thư nhận các lời chúc ngẫu nhiên được chọn lọc tinh tế.
- 📱 **Tối ưu Mobile**: Tương thích mượt mà trên smartphone, tự động gợi ý mở bằng trình duyệt ngoài (Safari / Chrome) khi quét từ app Zalo/TikTok/Facebook.
- ⚡ **Tốc độ tải nhanh**: Mã nguồn độc lập, tối ưu hoá hiệu năng.

## 🚀 Hướng dẫn chạy & Xem trực tiếp
- Mở trực tiếp file `index.html` trên trình duyệt.
- Hoặc truy cập đường link đã được deploy trực tuyến.
